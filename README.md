# PRS-brain-cognition
Scripts for studying age-related links between polygenic risk, brain measures, and cognition in large datasets (e.g., UK Biobank).
Source and citation:
Chen HJ, et al. Polygenic risk for Alzheimer's disease in healthy aging: age-related and APOE-driven effects on brain structures and cognition. 
Genome Med. 2025 Oct 21;17(1):126. 
doi: 10.1186/s13073-025-01548-z. PMID: 41121378; PMCID: PMC12539216.
